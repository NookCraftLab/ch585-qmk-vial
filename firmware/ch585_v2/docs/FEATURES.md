# CH585 QMK/Vial 三模键盘固件 - 功能详细说明

本文档列出固件已实现的功能和具体参数。

---

## 一、USB 功能

### 1.1 双口同时工作

- 高速口（USB2，PB12/PB13）和全速口（USB1，PB10/PB11）同时初始化
- 插任意一个口都能识别和使用
- 不做口切换

### 1.2 USB 接口配置

| 接口号 | 功能 | 端点 | 报告大小 |
|--------|------|------|----------|
| 接口0 | 键盘 HID | EP1 IN | 8 字节 |
| 接口1 | 鼠标 HID | EP2 IN | 6 字节 |
| 接口2 | Raw HID（Vial） | EP3 IN + EP3 OUT | 32 字节 |

### 1.3 Raw HID 参数

- 接口号：2
- 端点：EP3 IN（0x83）+ EP3 OUT（0x03）
- 传输类型：中断传输
- 包大小：64 字节
- 报告大小：32 字节
- 报告描述符长度：25 字节（0x19）
- Usage Page：0xFF60
- Usage：0x61

### 1.4 USB 描述符参数

- 设备描述符 bDeviceClass：0x00
- 配置描述符 wTotalLength：0x5B（91 字节）
- 配置描述符 bNumInterfaces：3
- 高速口 HID 描述符偏移：接口0=18，接口1=43，接口2=68
- 全速口 HID 描述符偏移：接口0=18，接口1=43，接口2=68

### 1.5 Vial 参数

- 序列号魔数：`vial:f64c2b3c`
- VIAL_KEYBOARD_UID：`{0x43, 0x48, 0x35, 0x38, 0x35, 0x45, 0x56, 0x42}`
- 支持 Vial 全功能改键

## 二、蓝牙功能

### 2.1 蓝牙基本参数

- 蓝牙版本：BLE 5.x
- 发射功率：0dBm（`LL_TX_PWR_0_DBM`）
- 多设备：支持多设备切换
- HID 报告长度：8 字节（mods + reserved + keys[6]）

### 2.2 蓝牙连接间隔（阶梯式）

| 档位 | 连接间隔 | 连接间隔（单位1.25ms） | 适用时段 |
|------|----------|--------------------------|----------|
| L0 | 100ms | 80 | 0~30 分钟 |
| L1 | 300ms | 240 | 30~90 分钟 |
| L2 | 500ms | 400 | 90~180 分钟 |
| L3 | 1000ms | 800 | 180 分钟以上 |

- 唤醒立即恢复 L0（100ms）
- 连接间隔上限：1000ms

### 2.3 蓝牙连接参数

- Supervision Timeout：500（5 秒，单位 10ms）
- Slave Latency：0
- 连接参数更新防抖：两次请求至少间隔 5 秒（`PARAM_UPDATE_MIN_INTERVAL_MS=5000`）

### 2.4 蓝牙广播（断开状态，阶梯式）

| 阶段 | 广播间隔 | 适用时段 |
|------|----------|----------|
| 快速广播 | 100ms | 0~30 秒 |
| 中速广播 | 500ms | 30 秒~5 分钟 |
| 慢速广播 | 2000ms | 5 分钟以上 |

### 2.5 蓝牙 HID 报告去重

- 去重位置：`ble_send_report_internal()`
- 去重逻辑：比较当前报告和 `last_sent_report`，完全相同且 `last_sent_report_valid=true` 则跳过
- 发送成功才更新 `last_sent_report`，发送失败不更新
- 发送失败不重试，直接放弃（QMK 矩阵扫描 10ms 一次自动重发）
- 不影响快速连击（按下/松开报告内容不同都会发送）
- 不影响按住不放（操作系统 auto-repeat 处理连续输入）

### 2.6 蓝牙协议栈关键配置

- `g_LLE_IRQLibHandlerLocation` 初始化为 `LLE_IRQLibHandler` 地址
- 链接 `libCH58xBLE.a` 加 `--whole-archive`
- TMR0 被 BLE 协议栈占用，应用层用 TMR1/TMR2/TMR3

## 三、低功耗功能

### 3.1 WFI 低功耗

- 主循环 `platform_run()` 后加 `__WFI()`
- 任何中断（按键、蓝牙、定时器）都能唤醒
- 零睡死风险

### 3.2 睡眠管理

- 无操作进睡眠超时：10 分钟（`POWER_SLEEP_TIMEOUT_MS`）
- 有线模式不进睡眠
- 睡眠时关 LED
- 按键唤醒

### 3.3 电源状态

| 状态 | 说明 |
|------|------|
| POWER_STATE_ACTIVE | 正常使用 |
| POWER_STATE_SLEEPING | 睡眠（低功耗） |

### 3.4 预期续航

- 电池容量：1000mAh
- 每天使用：5 小时
- 预期续航：12-18 天（待实际测试验证）

## 四、指示灯功能

### 4.1 LED 硬件

- LED0：PB14，低电平点亮，连接状态灯
- LED1：PB15，低电平点亮，电源灯
- GPIO 模式：推挽输出，5mA

### 4.2 LED0 连接状态灯

| 状态 | 表现 | 参数 |
|------|------|------|
| 正常使用 | 熄灭 | - |
| 有线插入 | 常亮 2 秒后熄灭 | 常亮持续 2000ms |
| 配对中 | 快闪 3Hz | 亮 100ms / 灭 233ms |
| 回连中 | 慢闪 1Hz | 亮 200ms / 灭 800ms |
| 连接成功 | 常亮 2 秒后熄灭 | 常亮持续 2000ms |

### 4.3 LED1 电源灯

| 状态 | 表现 | 参数 |
|------|------|------|
| 有线模式（USB连接） | 常亮 | - |
| 蓝牙模式（电池供电） | 熄灭 | - |
| 低电量（<20%，蓝牙模式） | 慢闪 1次/3秒 | 亮 200ms / 灭 2800ms |

- 低电量阈值：20%（`POWER_LOW_BATTERY_THRESHOLD`）
- 有线模式下低电量不影响 LED1（保持常亮）

### 4.4 指示灯驱动

- 独立驱动文件：`led_indicator.c/h`
- 状态机管理，非阻塞
- `led_indicator_task()` 调用位置：`protocol_usb.c` 的 `platform_run()` 里，`TMOS_SystemProcess()` 之前

## 五、电源管理功能

### 5.1 电池管理

- 电池电量获取：`battery_get_level()`
- 当前电池电量：模拟值 100%（评估板无电池检测电路）
- 低电量阈值：20%

### 5.2 模式管理

| 模式 | 说明 |
|------|------|
| 有线模式 | USB 连接，不进睡眠，LED1 常亮 |
| 蓝牙模式 | 电池供电，可进睡眠，LED1 熄灭（低电量时慢闪） |

- 模式切换：USB 插入自动进有线模式，USB 拔出自动退有线模式
- 模式记忆：`ble_save_mode()` 保存模式状态

### 5.3 活动检测

- 最后活动时间：`last_activity_time`
- 活动更新：按键、鼠标等操作时更新
- 无操作超时：10 分钟后进睡眠

## 六、系统配置

### 6.1 时钟

- 系统时钟：`CLK_SOURCE_HSE_PLL_62_4MHz`（外部晶振，62.4MHz）
- 启动文件：`startup_CH585.S`

### 6.2 内存占用

| 区域 | 已用 | 总量 | 使用率 |
|------|------|------|--------|
| FLASH | 208776 B | 448 KB | 45.51% |
| RAM | 34772 B | 128 KB | 26.53% |

### 6.3 编译配置

- BLE_ENABLE：ON
- ESB_ENABLE：OFF（2.4G 待开发）
- USB_PORT_CONFIG：USB_PORT_DUAL_BOTH（值4，双口同时工作）

### 6.4 GPIO 中断

- GPIO_A_IRQn：17
- GPIO_B_IRQn：18
- 使用 SDK 定义的中断号，不硬编码
